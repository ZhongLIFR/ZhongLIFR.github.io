# Institution logos

Used to identify the institutions in the owner's education and employment history. Retrieved on 2026-10-08; marks remain the property of their respective institutions.

- **Great Bay University:** [official identity page](https://www.gbu.edu.cn/about_us.html), [original logo lockup](https://www.gbu.edu.cn/Uploads/Picture/2026/05/15/s6a0687f474ce4_compress.png). `gbu.png` is unchanged; CSS frames the standalone GBU mark at the left.
- **USTC:** [official Suzhou institute logo download page](https://sz.ustc.edu.cn/wdxz_show/13.html), [blue/red seal sheet](https://sz.ustc.edu.cn/upload/202106/24/202106241717068493.jpg). `ustc-seals.jpg` is unchanged; CSS displays the blue seal at the left.
- **Leiden University:** [reference homepage](https://polaris-jz.github.io/), [seal asset](https://polaris-jz.github.io/images/Leiden_logo.jpeg). The source is PNG data despite its JPEG extension; it is stored unchanged as `leiden.png`.
- **TUM:** [official website](https://www.tum.de/), [official vector path](https://www.tum.de/typo3conf/ext/in2template/Resources/Public/Images/Backend/tum-logo.svg). `tum.svg` preserves the vector geometry, using blue (#0065BD) on white instead of the footer's white variant.
- **ENSAI:** [official website](https://ensai.fr/), [official logo](https://ensai.fr/wp-content/uploads/2019/05/Ensai-logo.png). `ensai.png` is unchanged.
- **Tongji University:** [Wikipedia institution page](https://en.wikipedia.org/wiki/Tongji_University), [logo file description](https://en.wikipedia.org/wiki/File:Tongji_Uni_logo.svg), [250px PNG](https://thumb.wikimedia.org/wikipedia/en/thumb/a/a4/Tongji_Uni_logo.svg/250px-Tongji_Uni_logo.svg.png). `tongji.png` is unchanged.

Assets are served locally; school links open the official institution websites. No photo, SVG geometry, or wordmark is generated.
